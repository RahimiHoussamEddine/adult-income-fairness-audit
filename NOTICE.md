# Data sources and attribution

## UCI Adult dataset

This repository uses the Adult dataset from the UCI Machine Learning
Repository:

- Dataset page: https://archive.ics.uci.edu/dataset/2/adult
- DOI: https://doi.org/10.24432/C5XW20
- Citation: Becker, B. & Kohavi, R. (1996). Adult [Dataset]. UCI Machine
  Learning Repository.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0).

The data were extracted from the 1994 U.S. Census database. The source
publisher describes the target as income above $50,000 per year. Raw data files
are excluded from Git. This project is independent and is not endorsed by UCI.

## Fairlearn

Group-metric calculations use Fairlearn's MetricFrame. The implementation and
terminology follow the Fairlearn documentation:

- https://fairlearn.org/v0.15/user_guide/assessment/common_fairness_metrics.html
- https://fairlearn.org/v0.15/user_guide/assessment/confidence_interval_estimation.html
